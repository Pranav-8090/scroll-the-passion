# 🎬 Scroll The Passion

**Scroll The Passion** is a feature-rich, full-stack short-video sharing platform (similar to Instagram Reels) built to showcase modern web development skills using React and Spring Boot.

## 🚀 Features
* **User Authentication:** Secure login and registration system.
* **Reels Feed:** Scroll through dynamic video reels.
* **Upload Reels:** Share your passion by uploading new video content.
* **Engagement:** Interactive Like, Save/Bookmark, and Comment functionalities.
* **Responsive UI:** Clean and user-friendly interface designed for seamless viewing.

## 🛠️ Tech Stack
* **Frontend:** React.js, Vite, Tailwind CSS / CSS, Axios
* **Backend:** Java, Spring Boot, Spring Security, REST APIs
* **Database:** MySQL

## ⚙️ Getting Started (Local Setup)

### Prerequisites
* Node.js & npm installed
* Java JDK (17 or higher)
* MySQL Database

### 1. Clone the Repository
git clone https://github.com/YOUR_USERNAME/scroll-the-passion.git

### 2. Run the Backend (Spring Boot)
- Open the backend folder in your IDE (IntelliJ / Eclipse / VS Code).
- Configure your MySQL database credentials in `application.properties`.
- Run the Spring Boot application.

### 3. Run the Frontend (React)
- Navigate to the frontend folder:
  cd frontend
- Install dependencies:
  npm install
- Start the development server:
  npm run dev
